## What was built

A curated directory of free genealogy sources and research paths, published as
docs plus a fully static HTML site generated by a build script. Content:

- **25 hand-maintained source entries** in `data/sources.json`, covering all
  goal areas: FamilySearch (record search, full-text search, wiki, catalog),
  state/county archives (NARA, NARA Catalog, CoSA state-archive directory,
  USGenWeb, UK National Archives), census lookups (NARA 1950 census portal,
  Steve Morse one-steps, NARA extraction forms), free newspaper routes
  (Chronicling America, Newspapers.com-via-library-card, FultonSearch,
  Google News Archive, Trove, NYS Historic Newspapers, LoC newspaper
  directory), cemeteries (Find A Grave + ANC Explorer), and more free help
  (Cyndi's List, RAOGK, DPLA, Ancestor Hunt).
- **Per-entry policy fields**: `requirements` tag (nothing / free account /
  library card), `verify_date` (last human check the link worked and was
  still free), and `_meta.last_reviewed`.
- **Four hand-maintained guide pages** in `site-content/`:
  Start Here (first-hour session), Find A Grave etiquette (do/don't +
  example photo request), Citing-a-source starter card (five-fact card +
  citation example), Offline Research Binder checklist.
- **`build.py`** (Python stdlib only): renders the data into 6 static pages
  with inline CSS, no JavaScript, no remote assets, no trackers.
- **`tests/test_build.py`**: 31 tests verifying data policy and page
  rendering (below).
- README, MIT LICENSE, .gitignore.

Policy enforced on every entry: **no paywalls, no affiliate links**. The
sibling projects (family-history manual, oral-history interview kit,
official-help directory) are kept distinct in scope per the original goal.

## How to run it

```bash
python3 build.py                        # rebuild site/ (default output)
python3 build.py --out /tmp/anywhere    # build somewhere else
python3 -m unittest discover tests -v   # run the test suite
```

Open `site/index.html` in a browser; the site is self-contained (works
offline, no server needed). Environment used for verification: Linux,
Python 3.13.5, node v20.19.2 (present; project itself uses Python only).

## Known gaps

1. **Link freshness decays**: verify dates go stale. The test suite fails
   once any date exceeds 180 days - that is deliberate, but it means the
   suite needs a re-verify pass roughly every quarter.
2. **Coverage is intentionally narrow**: 25 entries, U.S.-weighted with two
   international anchors (UK NARA, Trove). State-level archive pages
   themselves are not yet individually listed (only the CoSA master
   directory).
3. **No link-robot in CI**: HTTPS/reg-listing checks are structural, not
   live fetches (kept deliberately to stay local-first and network-free in
   tests).
4. Find A Grave memorials/photos change without notice; the etiquette page
   asks users to record the memorial URL + view date, but the directory
   itself cannot track those edits.
5. No search/filter UI on sources.html beyond category anchors - fine for
   25 entries, will need JS or serverless filtering if the list grows past
   ~60.
